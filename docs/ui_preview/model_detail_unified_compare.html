模型詳細資料
控制項統一預覽

同一份模型狀態，套用兩種統一規則。兩側操作同步，選取狀態、資訊密度與掃描性可以直接對照。 預覽聚焦「模型類型、輸入／輸出模式、能力」；PDF 模式代表原生文件能力，文字擷取是自動 fallback，不再是一個可選模式。

A

新樣式統一（已封存）

膠囊晶片 · 圖示 + 標籤 · 可換行

Archived · Chip system
五個輸入模式一列可容納，窄寬度自然換行；類型與能力也使用同一種選取語言。
B

舊樣式統一（已採用）

分段控制器 · 等寬 · 緊湊對齊

Selected · Segmented system
所有多選項壓成同高控制列；五個模式在 390px 寬仍可容納，但沒有圖示。
01

模型類型不加入「圖像」

類型是用途／端點（聊天、嵌入），不是能力。圖像生成是 output modality，現在由「輸出模式 → 圖片」與 Images API 路由表達。

02

原生輸入不是多餘，但不該獨立成區塊

PDF 模式就是原生 PDF。文字擷取是所有文字模型的自動 fallback，不應再成為第二個模式；音訊沒有 fallback，因此也不需要額外開關。

03

統一的邊界

所有候選項選取用同一種語言；導航 tabs、文字輸入框、開關不強行改成 chip。統一是「選取控制項」的統一，不是把所有元件做成同一顆膠囊。
